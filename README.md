# RAGE CITY — version jouable dans le navigateur

Prototype du jeu décrit dans le document de conception *RAGE CITY*.

**Ouvre [la page](https://johnibgg.github.io/rage-city/) sur ton téléphone,
en paysage.** Rien à installer.

- moitié gauche de l'écran : le joystick naît là où le pouce se pose
- moitié droite : la caméra
- bouton rouge : frapper · bleu : esquiver · or : capacité spéciale

Univers fictif. Les personnages sont des archétypes ; aucun ne représente
une personne réelle.
